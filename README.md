 Monitoring & Observability

To ensure high availability and performance, I implemented a monitoring solution using **Amazon CloudWatch**:

 **Custom Dashboard:** Real-time visualization of CloudFront traffic (Request rates).

**Proactive Alarming:** Configured **CloudWatch Alarms** to trigger when error rates exceed 5%.

**Notifications:** Integrated **Amazon SNS** to receive instant email alerts if the site goes down or faces performance issues.
